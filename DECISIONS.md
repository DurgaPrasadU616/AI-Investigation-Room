# Decisions

- 2026-10-30, M1: Removed registration, login, JWT middleware, user persistence, and My Cases UI. The app now starts at a public home screen. Server configuration follows v2; CORS reads `CLIENT_URL`; optional media flags default false.
- 2026-10-30, M1 runtime: Atlas connected and `/api/health` returned `ok`; the React app ran under Vite on port 5174 because port 5173 was occupied at that time. Client production build and lint passed.
- 2026-10-30, M2: Added the v2 Case schema, difficulty counts, Gemini JSON response schema, Zod and logical consistency checks with two retries, premise screening, and public case creation/read routes. The service uses the configured model and cancels the SDK call at its 60-second timeout. Live Easy generation succeeded after two timed-out Gemini attempts; it returned 3 suspects, 5 clues, 2 hints, and a real title. Its active-case GET response omitted the solution, motives, clue logic, and undiscovered content.
- 2026-10-30, M3: Added discovery, hint, accusation, and result endpoints. Accusation is an atomic active-to-completed update, score comes only from stored progress, and the API response is sanitized until accusation. Added an Atlas-backed integration test for acceptance criteria 3, 4, and 6. `npm test` passed (1 test); server lint passed. An initial sandboxed test could not resolve Atlas DNS, so the passing run was repeated with network access.
- 2026-10-30, M4: Replaced placeholder routes with Home, Create, Investigation Room, Accusation, and Results pages. Pages use the v2 API, show discovered clues and hints, display score results, and keep investigator notes in localStorage. Client lint and production build passed.
- 2026-10-30, M5: Added rotating generation flavor text, the 8-second server-wake message, a labeled generation retry, result-before-accusation redirect, saved local notes, mobile layouts, and error/empty states. Discovery and hint progress use atomic database updates. Tightened Easy contradiction and Hard cross-reference checks, and changed named-person premise screening to avoid rejecting ordinary sentence starts such as "The college canteen". Client/server lint and the Atlas-backed acceptance test passed; Vite returned HTTP 200 on port 5175.
- 2026-10-30, M6: Added Vercel SPA rewrites and a Render service blueprint with a health check and unset secret variables. Final API startup connected to Atlas on port 5000; health returned `ok`; Vite Home and direct room routes returned HTTP 200 on port 5173; frontend production build, lint, and acceptance test passed. Live deployment and production URL testing require the user's hosting projects and deployment values, which are not present in this workspace.
- 2026-10-30, M7 optional media: Implemented image and CCTV frame generation behind `ENABLE_IMAGES` and `ENABLE_CAM`, both default false. Enabled modes require `GEMINI_IMAGE_MODEL`; media failures are logged and leave the playable case intact. Generated media is only exposed for discovered clues. The official [`@google/genai` image generation guide](https://ai.google.dev/gemini-api/docs/generate-content/image-generation) uses `models.generateContent`, `responseModalities: ['IMAGE']`, and image bytes in `inlineData`.
